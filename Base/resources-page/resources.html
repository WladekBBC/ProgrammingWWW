FAQ – szybkie odpowiedzi

Jak często aktualizować system po instalacji?

Warto uruchamiać sudo apt update && sudo apt upgrade przynajmniej raz w tygodniu, aby utrzymać serwer w najnowszej i bezpiecznej wersji.

Jak monitorować podstawowe parametry serwera?

Zainstaluj pakiet htop lub używaj wbudowanego polecenia top. Dla logów systemowych korzystaj z journalctl oraz plików w /var/log.

Czy mogę zdalnie zarządzać serwerem?

Tak, skonfiguruj SSH i korzystaj z kluczy publicznych dla bezpiecznego logowania. Rozważ też ustawienie ufw aby ograniczyć dostęp do portów.

Jak szybko rozwiązać problem z siecią?

Sprawdź status usług poleceniem systemctl status NetworkManager, upewnij się że Twój interfejs ma adres IP (ip addr) i zweryfikuj DNS korzystając z resolvectl status.

Checklist – po instalacji

  1. Zmień domyślne hasła i utwórz użytkowników z ograniczonymi uprawnieniami.
  2. Włącz zaporę sieciową (sudo ufw enable) i otwórz tylko wymagane porty.
  3. Skonfiguruj automatyczne kopie zapasowe katalogów krytycznych.
  4. Monitoruj wykorzystanie zasobów za pomocą narzędzi takich jak netdata, glances lub Prometheus.
  5. Dokumentuj zmiany i konfigurację, aby ułatwić przyszłe audyty.
